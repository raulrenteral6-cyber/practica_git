💡 Ideas para practicar Git con este proyecto:

  1. Crear una rama: git checkout -b feature/nuevo-lenguaje
  2. Editar: Agrega un nuevo elemento en el arreglo items dentro de js/app.js
  3. Guardar y commitear: git commit -am "feat: agregar lenguaje Kotlin"
  4. Merge: Vuelve a main e integra tus cambios con git merge feature/nuevo-lenguaje
